02 — Behind the page

From stanza to image, in three steps.

01

You write

A poem, a fragment, even a single evocative line — plus an optional rendering style.

02

Versilume reads it

Each scene is summarized, scored for its dominant emotion and theme, and scanned for concrete visual details — the same three-part reading (emotion, theme, imagery) used in poem-to-image research literature.

03

It's painted back

One image per scene returns to this page, each labeled with the mood and theme Versilume read from it — yours to view full-size, download, or send back for another pass.

Versilume

Built for poets who want to see what they wrote.

Backend contract: POSTs to POST /api/v1/generate with JSON { poem, force_single_image, style }. Response shape: { poem, num_segments, segments: [{segment_id, lines, elements:{summary, dominant_emotion, theme, visual_elements}, image_prompt}], images: [{segment_id, image_prompt, image_base64, mime_type, model_used}] }. Images are raw base64 + an explicit mime_type (not a URL) — rendered here as a data: URI.
